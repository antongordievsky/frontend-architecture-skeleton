# Frontend foundation — an architectural skeleton

A take-home exercise: build the architectural skeleton of a frontend for a crypto-tax product —
project structure, dependency boundaries, an API layer over a mocked backend, representative
routing, a design-system foundation, quality tooling and one thin example page, with the reasoning
written up in a one-page `ARCHITECTURE.md`. TypeScript; `docker compose up` must be the only
command needed to run it.

The work starts in the next commit.
